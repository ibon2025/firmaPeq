# Pruebas Firma Pequeña

Proyecto Java de pruebas para aplicaciones de firma digital.

## Estructura del Proyecto

```
pruebasFirmaPequeña/
├── src/
│   ├── main/
│   │   ├── java/          # Código fuente principal
│   │   └── resources/     # Recursos de la aplicación
│   └── test/
│       ├── java/          # Tests unitarios
│       └── resources/     # Recursos para tests
├── pom.xml                # Configuración Maven
└── README.md              # Este archivo
```

## Requisitos

- Java 11 o superior
- Maven 3.6 o superior

## Construcción

```bash
mvn clean compile
```

## Ejecución de Tests

```bash
mvn test
```

## Instalación de Dependencias

```bash
mvn install
```
